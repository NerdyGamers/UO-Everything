# Peerless Rewards

Named artifacts dropped by the peerless bosses — the toughest single encounters in Mondain's Legacy-era content. Each boss has its own signature drops, while a few items (Crimson Cincture, Evocaricus, Feathernock, Swiftflight, Maleki's Honor) are listed as dropping from any peerless. Several bosses also drop rare pet crystals or statuettes.

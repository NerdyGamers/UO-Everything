# Doom Artifacts

The Doom artifact set comes from the Doom Gauntlet, introduced with Age of Shadows: killing the Gauntlet's bosses — Dark Fathers, Darknight Creepers, Fleshrenderers and Impalers, Shadow Knights, and Abyssmal Horrors — can award an artifact directly into the killer's backpack. A smaller set of Doom artifacts are stealables taken with the Stealing skill instead of boss drops.

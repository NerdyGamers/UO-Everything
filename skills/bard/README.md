# Bard Skills

**Canon scope:** Canon (highlight shard-specific tweaks as non-canon when needed).

Bard skills use music to control the battlefield — weakening, calming, or enraging creatures. Every bard ability requires an instrument in hand and checks [Musicianship](musicianship.md) first.

## Skills in this group
- [Musicianship](musicianship.md) — the foundational skill; required for all other bard abilities.
- [Discordance](discordance.md) — debuffs a target creature's stats, resists, and damage.
- [Peacemaking](peacemaking.md) — calms creatures, stopping their attacks.
- [Provocation](provocation.md) — incites two creatures to fight each other.

## Cross-cutting notes
- Individual skills cap at 100 (120 with power scrolls); the total skill cap is 700 points.
- Success checks Musicianship + the specific bard skill against the target's barding difficulty.
- Instruments come from [Carpentry](../crafting/carpentry.md); exceptional and special-wood instruments aid bards.
- The classic bard template trains all four skills together.

# Night Sight

A first circle magery spell that grants vision in darkness.

## Casting

Words of power: *In Lor*. First circle magery spell. Mana cost: 4. Minimum Magery skill: 0. Reagents: spider's silk, sulfurous ash.

## Effect

Lets the target see in the dark as if it were day for a time.

## Notes

One of the original magery spells, dating to the game's launch. See [Magery](../magery.md).

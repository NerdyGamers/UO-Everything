# Miscellaneous skills


The scholarly and flavor skills that fit no other group: evaluating gear, begging, mapmaking, detective work, and identification.

- [Arms Lore](arms-lore.md) — judge the condition of weapons and armor.
- [Begging](begging.md) — plead with NPCs for coins.
- [Cartography](cartography.md) — decode treasure maps; craft maps.
- [Forensic Evaluation](forensic-evaluation.md) — examine corpses; learn the killer's name.
- [Item Identification](item-identification.md) — reveal magic item properties.
- [Taste Identification](taste-identification.md) — identify food and potions; detect poison.

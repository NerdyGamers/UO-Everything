# Honorable Execution

A Bushido finishing strike that attempts to end a weakened enemy with a single blow.

## Mechanics

Requires around 25 Bushido and costs no mana. If the strike kills the target, the samurai is healed and gains a brief swing-speed bonus. If the target survives, the samurai is left weakened — resistances drop and no special moves can be attempted — until a successful parry ends the weakness. The damage bonus scales with Bushido skill.

## Notes

Introduced with the Samurai Empire expansion. The signature samurai execution move, tied to the honor-driven flavor of the skill. See [Bushido](../../bushido.md) for the Perfection system, which rewards consecutive honorable kills.

# Ninjitsu Abilities

The eight special abilities of the [Ninjitsu](../../ninjitsu.md) skill, introduced with the Samurai Empire expansion.

- [Animal Form](animal-form.md) — transform into beasts for unique bonuses
- [Backstab](backstab.md) — high-damage strike from stealth
- [Death Strike](death-strike.md) — delayed burst punishing fleeing targets
- [Focus Attack](focus-attack.md) — damage bonus amplifying weapon properties
- [Ki Attack](ki-attack.md) — damage growing with distance traveled
- [Mirror Image](mirror-image.md) — decoys absorbing incoming attacks
- [Shadowjump](shadowjump.md) — short-range teleport while hidden
- [Surprise Attack](surprise-attack.md) — stealth strike crippling enemy defense

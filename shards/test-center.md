# Test Center

Test Center (TC) is the public testing shard where upcoming publishes are tried out before they go live. Players copy characters there to experiment with new systems risk-free.

## How it works

When a new publish enters testing, Broadsword opens Test Center and players can copy one or more of their production characters to it through account management. The copy is a snapshot — nothing done on TC affects the live character. TC commonly has accelerated skill gain and free resources so testers can try endgame content quickly (community recollection on the exact current amenities).

Test Center is where patch bugs get found: players run the new dungeons, test balance changes, and report issues on the official forums. It is wiped periodically, so nothing there is permanent. For trying a template idea or previewing a publish, it beats theory-crafting on a [production shard](official-shards.md).

## Era notes

Test Center has existed in some form since the earliest publishes; the character-copy flow through account management is the modern version of older manual copy processes.
